Known API limit and recovery

GitHub's synchronous merge API atomically checks the head SHA, not an expected base SHA. Read base immediately before dispatch and verify the actual integrated tree afterward. Concurrent base drift cannot be described as verified exact integration: retain the Issue/claim, invalidate the result and require reconciliation. Do not silently add branch protection or broaden permissions. Merge queues/stacked or unsupported delivery require their own qualified path and remain blocked.

Foreground close and Pause cancel new actions but do not undo a noncancelable remote effect. Reconcile before further mutation. Reopening displays preserved candidate/decision/uncertainty; it does not automatically repeat a merge. Remote read failure never proves absence. Existing immutable run/source/effect records remain readable.
