Diagnosis and smallest implementation

The connection and workspace completion callbacks already show the owned window, focus it and focus its web contents. Their macOS application can remain inactive after an external AppKit helper takes foreground focus. Electron documents app.focus({steal:true}) as application activation even when another application is active. Add that macOS-only call inside the existing completion/closing/window guards, immediately before the existing window-focus calls. Apply it to the two callbacks that return from native secure entry and folder entry. Preserve all existing authority checks and the native focus assertion.
