# Installed repository home

Use the installed `scripts/resolve-home.mjs` with no arguments; from elsewhere invoke its absolute path. It anchors to the installed script file, never cwd, and returns `root`, `repository`, `profilePath`. See [CLI and evidence format](evidence.md) for supported remote transports and fail-closed behavior. Resolve this script from the canonical installation before invoking it; do not substitute the upstream framework's resolver for an adopter's.

For an installed lifecycle skill, resolve its own repository home from the installed canonical skill location and adjacent repository-owned `pipeliner.config.json`, not from the caller's current directory or the upstream framework source. A provider adapter must resolve its canonical link first. Inspect the enclosing `AGENTS.md`, profile and real Git worktree root. Use argument-based Git calls with an explicit working directory; never interpolate an untrusted path or remote into shell code.

Verify both fetch and push `origin` identities against the profile's owner/name and actual repository identity. Different transport URLs may identify the same repository, but a mismatched push destination, missing root/profile, conflicting nested installation or ambiguous identity blocks mutation. A profile assertion alone is insufficient. Report the verified absolute checkout and repository identity. Do not infer an auxiliary application, infrastructure or deployment repository; obtain explicit scope before crossing home boundaries.

Installed work, review, release, close, audit, update and monitor requests use this verified home without asking the PM to repeat its location. An explicit target must agree with the installation being used or be resolved deliberately before mutation. Global/uninstalled skills without a verifiable home require a target question. First adoption still requires an explicit existing target or new-repository intent; never infer it from cwd or this framework checkout. Upstream source resolution for updates is separate from adopter home resolution.
