Smallest increment and ordered plan

  1. Add one explicit source-only --qualify-soak option, valid only with --qualify-issues. Keep the existing native workload fixture alive for 24 hours after its initial assertions. Packaged startup continues refusing all qualification flags; qualification modules remain excluded from packages.
  2. Use the real foreground scheduler, protected stores, timers and renderer. Every minute check the disabled scheduling default, rotate cached workspace selection, measure local navigation feedback and collect process RSS/heap plus actual fixture catalog/model counters. Assert stable policy, no external fixture writes, no model calls and no additional catalog reads. Record monotonic and wall elapsed times separately.
  3. Write only finite numeric samples to one exclusive private file in the caller's already verified output directory. Bound sample count and bytes; retain incomplete evidence on failure. No provider content, repository names, credential values or arbitrary errors enter this file.
  4. The existing progress parser's ten-minute numeric ceiling would reject valid post-soak shutdown telemetry. Preserve its exact known-phase and known-field schema; accept nonnegative safe integer durations without a task deadline. Reject invalid/unsafe values. This changes telemetry only.
  5. Verify the measurement loop's completion/failure contract and progress boundary before implementation. Run focused checks and the complete configured npm run check on clean committed source. Start the original native workload plus soak once. Retain the exact process handle, continuously verified external storage, source/tree and start record. Inspect full results and cleanup after completion or cancellation.

Acceptance

A soak pass requires at least 86,400,000 monotonic milliseconds, complete initial/final samples, no observation gap exceeding two sampling intervals (120,000 ms), all original workload/native assertions, unchanged captured authority and zero additional model/catalog/write effects. Cached navigation p95 remains below 2,000 ms; sampled local navigation control feedback remains below 150 ms. Publish cold/warm traces and resource measurements without inventing a memory target. Any interruption, failed assertion or missing evidence is incomplete/failure, never a shortened pass.

An interrupted run must retain partial samples, fail to claim a soak pass and close/remove its owned processes and fixtures. Repeated cancellation signals must not detach cleanup. This Mac's testing policy stays outside repository code; the caller verifies its output paths and producer chain.

Risks, limits and non-goals

This is an actual source-app foreground soak with synthetic remote replies and disabled background operation. It does not qualify SMAppService, real provider/GitHub load, five full Development runs, Mac guest installation, packaged startup, Human usability or another OS. Keep those gaps separate. Sampling does not prove every frame or OS-service scratch route. Resource contention may fail the existing latency targets; preserve failure and diagnose its cause. Do not change product behavior, security controls, PM defaults, credentials, installed dependencies or unrelated processes for this experiment.
