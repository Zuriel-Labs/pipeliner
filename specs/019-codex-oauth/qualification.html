Passed, failed and not run

Not run or unproven: actual token expiry and renewal, forced managed-policy/provider approval, exhaustive built-in tool availability, a production Codex adapter inside the VM worker, full Chat-First PM flow, Windows/Linux and a complete Desktop app. No human PM Testing has occurred for this Issue.

Decision and next action

Recommendation for this Mac: use managed ChatGPT OAuth with a fresh CODEX_HOME, the real macOS HOME for Keychain lookup, explicit keyring storage, no-environment turns, and a scoped dynamic-tool broker. Treat the experimental tool API and any future built-in or mandatory provider gate as capability checks before autonomy. No API-key fallback or automatic approval is allowed. Issue #19 remains the authority for current lifecycle status and PM acceptance.
